TEXTJOIN
=TEXTJOIN(delimiter, ignore_empty, text1, [text2], …)
Joins a list of values into one cell using any separator — blanks skipped automatically.
What It Does
TEXTJOIN combines multiple text values or cell ranges into a single string, placing your chosen delimiter between each item. Unlike CONCATENATE, it handles entire ranges at once and skips empty cells when you set ignore_empty to TRUE — no more blank commas cluttering your output. Combine it with IF to filter which values get joined, and you've got a powerful one-formula summary tool.
Use Cases
Build a comma-separated list of active clients from a status tracker — without filtering
Pull all "In Progress" tasks into a single summary cell for your weekly report
Combine a team member's name, role, and department into one readable label cell
Join product tags or SKUs from a filtered range into a single exportable string
Example
A — Client Name B — Status
Sarah's BakeryActive
TechStart LtdActive
Jamie FreelancePaused
Corner Shop CoActive
Formula in C1:
=TEXTJOIN(", ", TRUE, IF(B2:B5="Active", A2:A5, ""))
✅ Sarah's Bakery, TechStart Ltd, Corner Shop Co
=TEXTJOIN(", ", TRUE, IF(B2:B10="Active", A2:A10, ""))
