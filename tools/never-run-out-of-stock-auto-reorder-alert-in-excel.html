Never Run Out of Stock:
Auto-Reorder Alert in Excel

Stop manually comparing stock levels against a minimum threshold. One formula flags the alert and tells you exactly how many units you're short.

=IF(B2<C2,"⚠️ Reorder — "&(C2-B2)&" units short","✅ "&(B2-C2)&" units above minimum")

B2 = current stock  |  C2 = minimum / reorder point

How It Works

1

IF(B2<C2, …, …) — checks whether your current stock is below the minimum threshold. If yes, it runs the reorder message; if no, it runs the safe message.

2

"⚠️ Reorder — "&(C2-B2)&" units short" — when stock is low, calculates exactly how many units you need to hit your minimum and shows it in the cell.

3

"✅ "&(B2-C2)&" units above minimum" — when stock is fine, shows the buffer you have. The moment you update a quantity, the status updates automatically.

Solopreneur

Physical Product Seller

You sell handmade or print-on-demand products and track stock in a spreadsheet. Add a minimum column and let this formula do the monitoring — no more selling items you've already run out of:

=IF(B2<C2,"⚠️ Reorder — "&(C2-B2)&" units short","✅ "&(B2-C2)&" units above minimum")

Result when low: "⚠️ Reorder — 12 units short". Result when safe: "✅ 8 units above minimum".

Small Business

Office or Workshop Supplies

You track consumables — printer paper, packaging materials, raw stock — in a shared sheet. Set a minimum for each item and this formula alerts you before you run out, not after:

=IF(D2<E2,"⚠️ Reorder — "&(E2-D2)&" units short","✅ "&(D2-E2)&" units above minimum")

Adapt column letters to match your layout. Copy the formula down for every row in your stock list.

Pro Tips

  • → Add conditional formatting: Highlight the row red when the status starts with "⚠️" using a custom CF rule: =LEFT(D2,1)="⚠"
  • → Add a reorder quantity column: Use =MAX(0, C2-B2) next to it to get just the number to order, without the text.
  • → Count how many items need reordering: Use =COUNTIF(D2:D20,"⚠️*") in a summary cell to see the total at a glance.
  • → Make the threshold dynamic: Replace the fixed minimum with a cell reference so you can adjust reorder points without editing the formula.
